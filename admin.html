Alur kerja admin

1. Periksa pesanan masuk dan hubungi pelanggan untuk konfirmasi.

2. Pastikan produk tersedia atau bisa disiapkan sesuai jadwal.

3. Untuk produk pre-order, konfirmasi harga, bahan, dan waktu terlebih dahulu.

4. Perbarui status pesanan setelah sistem database terhubung.

Pengaturan Stok

Stok tidak wajib untuk semua produk. Angka stok hanya untuk pengelola.

Aturan pengelolaan stok

• Pesanan terlebih dahulu: bahan disiapkan setelah admin menyetujui pesanan.

• Tersedia dari stok: catat jumlah produk siap jual.

• Bisa dari stok atau pesanan: admin memilih sumber pemenuhan saat konfirmasi.

• Status stok untuk pelanggan dapat diaktifkan per produk. Secara default, angka stok internal tidak ditampilkan di halaman toko.
